# Rakesh Choudhury — Portfolio

Modern React portfolio for Rakesh Choudhury.

## Stack

- React
- Vite
- Framer Motion
- Lucide React
- Plain CSS

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to GitHub Pages

This project is designed for the user-site repository:

`rkchoudhury.github.io`

1. Create a public GitHub repository named exactly `rkchoudhury.github.io`.
2. Copy this project into that repository.
3. Run:

```bash
npm install
npm run deploy
```

4. Visit `https://rkchoudhury.github.io`.

### Resume

Replace `public/resume.pdf` with your actual resume PDF before deploying.

### Project links

The initial project cards point to your GitHub profile because the resume does not contain the individual project URLs. Replace those values in `src/App.jsx` when you have the actual repository links.
